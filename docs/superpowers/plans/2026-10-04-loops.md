# Loops Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (default) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every open ball (merged PRs' manual steps, agents' blocked-on-human items) lives as a `loop`
issue in `jonathanmoregard/.claude`; agents add/list/update/close loops through one gated MCP tool;
the swipe GUI shows them in a Loops deck without ever holding a token.

**Architecture:** `pr_swipe/loops.py` owns every rule (fixed repo, `loop` label check, size caps,
dedup key, rate limit) over the existing `GitHub` client. Three thin users: the stdio MCP server
(`pr-swipe-loops-mcp`), the user service `pr-swipe-loops` (files merged PRs' steps, writes
`inbox/loops/open.json`, applies GUI requests from `outbox/loops/`), and the GUI deck (reads the
snapshot, writes requests). Spec: `docs/superpowers/specs/2026-10-04-loops-design.md`.

**Tech Stack:** Python 3.14, PySide6, `mcp` 1.27 (FastMCP), GitHub REST via `pr_swipe.github`,
pytest + pytest-qt, Nix flake.

    def list_issues(self, repo, label, state="all"):
        return self._pages(f"/repos/{repo}/issues?state={state}&labels={urllib.parse.quote(label)}", repo=repo)

    def get_issue(self, repo, n):
        return self._req("GET", f"/repos/{repo}/issues/{int(n)}", repo=repo)[1]

    def create_issue(self, repo, title, body, labels):
        return self._req("POST", f"/repos/{repo}/issues", repo=repo,
                         body={"title": title, "body": body, "labels": list(labels)})[1]

    def edit_issue(self, repo, n, **fields):
        return self._req("PATCH", f"/repos/{repo}/issues/{int(n)}", repo=repo, body=fields)[1]

```python
KINDS = ("followup", "blocked", "decision", "chore"); OWNERS = ("human", "agent")
TITLE_MAX, BODY_MAX, WRITES_PER_MIN = 120, 4000, 30
KEY_RE = re.compile(r"<!-- loop-key: ([0-9a-f]{16}) -->")
DATE = r"\d{4}-\d{2}-\d{2}"

class LoopError(ValueError): ...

def loop_key(*parts) -> str  # sha256 of whitespace-normalised, lower-cased parts joined by "\x1f", [:16]

@dataclass(frozen=True)
class Loop:
    number: int; title: str; kind: str; owner: str; source: str; state: str; reason: str
    due: str; until: str; key: str; url: str; created_at: str; body: str
    def as_dict(self) -> dict  # dataclasses.asdict

def from_issue(i) -> Loop     # labels → kind/owner/source; body lines due:/until:; key marker; body text
                              # without the machine lines

class Loops:
    def __init__(self, gh, repo, clock=time.time)
    def list(self, state="open") -> list[Loop]
    def add(self, title, body="", kind="chore", owner="human", source="", due="", key="") -> tuple[Loop, bool]
    def snooze(self, n, until)          # until "" clears
    def set_owner(self, n, owner)
    def set_due(self, n, due)
    def note(self, n, text)             # issue comment, size-capped
    def close(self, n, done=True)       # state_reason completed / not_planned
```

Every write: `_tick()` (rate limit over a 60 s window of `clock()`), `_loop(n)` fetches the issue and
raises `LoopError` unless it carries `loop`. `repo` is set once in `__init__`; no method takes a repo.
